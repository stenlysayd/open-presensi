# Open Presensi - Mobile Client (Flutter + GetX)

Aplikasi klien cross-platform untuk **Open Presensi** yang mendukung:
- Pemindaian cepat QR Code (*rapid scan*) secara massal oleh guru/petugas gereja.
- Kartu identitas QR digital pribadi untuk siswa dan jemaat.
- Mode **Offline-First**: presensi tersimpan di penyimpanan lokal saat internet mati, dan disinkronkan otomatis begitu jaringan online terdeteksi.
- Ringkasan statistik kehadiran harian/bulanan.

## Cara Menjalankan

1. Masuk ke direktori:
   ```bash
   cd client-flutter
   ```
2. Pasang dependensi:
   ```bash
   flutter pub get
   ```
3. Jalankan pada emulator atau perangkat fisik:
   ```bash
   flutter run
   ```
